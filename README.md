# 数字人文入门与研究准备指南

面向初学团队的数字人文科普与研究准备材料，重点介绍数字人文、OCR / HTR、语言学与计算文本研究。

**资料检索截止：2026年10月23日。** 本项目为范围性调研与学习资料，不是穷尽性系统综述；候选选题尚未逐项完成查新或实证验证。

正文包含14章，附录收录120项去重来源，区分58项学术读物与62项官方资源说明。每项来源保留原始链接、读取范围及适用边界。

## 内容范围

- 数字人文的基本概念、分支与实际项目。
- OCR、手写文字识别、版面理解、纠错和质量评价。
- 语料库、语言变化、文学文本与古代汉语处理。
- 基础工具、团队分工、候选课题及学习路线。
- 研究方法、证据边界与可追溯来源。

初次阅读建议先看正文第1、2、3、10、11章，再按需要查阅工具和论文。
