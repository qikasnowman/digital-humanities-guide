数字人文入门与研究准备指南

检索截止：2026年10月23日｜重点：数字人文 × OCR、数字人文 × 语言学｜面向：尚未接触本领域的团队

本报告回答四个问题：这个领域究竟研究什么；现实中已经做到哪一步；2024—2026年的论文在推进什么；零基础团队如何选择能落地、能验证、有研究意义的切入口。先铺开整个领域，再展开OCR与语言学，最后给出选题比较、学习路线和可追踪的文献表。

阅读方法 ：第一次只读第1、2、3、10、11节；准备选题再读第4—9节；查论文与工具时使用附录和配套文献表。网页报告提供章节折叠、目录和文献搜索，适合分次阅读。

证据说明 ：这是一份范围性调研和叙述性综合，不能宣称穷尽全球研究。重点检索中英文一手论文、正式论文库、研究机构、标准及工具官网。正式发表、预印本、进行中项目分开标注；“可读网页”与“可获取研究数据”也分开。候选选题和学习安排是本报告建议，尚未完成针对每个题目的查新或实证实验。

1. 先建立共同认识：数字人文是什么

1.1 用一句话理解

数字人文（Digital Humanities，DH）是一组围绕人文问题开展的数字研究实践：把文献、图像、声音、空间和文化活动转为可整理、可连接、可分析、可展示的材料，同时研究这些数字化过程如何改变知识。它包含资源建设、计算分析、数字编辑、公共传播与方法反思，边界并不只有一种划法。作为其中较偏计算研究的刊物，Computational Humanities Research明确要求论文扎根人文问题，并用计算、定量方法研究人文材料。CHR办刊范围

例如，研究一本地方志，可以逐页转录并建立可检索版本；也可以分析其中地名与人物关系，研究地方社会；还可以比较不同版本中某个词的意义。它们共享材料，却可能有完全不同的研究贡献。以下例子均是 研究设计示意，并非已完成的历史发现 。

1.3 你们考虑的三个方向是什么关系

方向 核心问题 典型成果 最应具备的能力

数字人文 × 语言学 怎样用真实材料研究语言结构、使用与变化 语料库、标注体系、语言现象研究、语言模型评测 语言学概念、语料设计、标注与统计

三者可以组成同一条研究链： 历史文献影像 → 可靠转录 → 语言标注 → 语言或人文问题 → 回到原件核查解释 。其中任何一步都可以成为研究重点，但论文应说明自己的主要问题和贡献。

1.4 与相邻领域的区别

  • 语料库语言学 围绕语料研究语言模式；可以使用当代口语，也可以使用古代文献，与DH有交叉。
  • 计算语言学/NLP 研究机器处理语言的方法和任务；一项通用分词或OCR算法，需要结合人文材料、问题和证据，才形成具体的DH交叉研究。
  • 计算社会科学 常研究群体、制度和行为；与数字历史、社会语言学、文化分析有大量交叉，研究尺度和解释目标可能不同。
  • 数字文化遗产 重视文化对象的记录、保存、访问和利用；它与考古、博物馆学、建筑史、艺术史及公共人文相连。
  • 文化分析/计算文学研究 关注文本、图像等文化材料中的模式，同时需要解释这些模式的历史与文化意义。

这些边界是便于入门的工作性划分，不是各学科统一同意的排他定义。判断项目时，建议先看“研究问题—材料—方法—验证”，再看它使用什么领域名称。

3. 现实发展到哪一步：观察项目、机构与服务

3.1 发展并不是所有旧方法同时被替代

一条常见的简化历史线索，是从Busa于1949年开始的拉丁文索引工作，看到索引、语料、文体与作者研究的长期积累。文本编码、数据库和网络数字出版，后来扩展了研究对象与成果形式。这不是所有地区唯一的起源或严格分期，也不意味着某一新技术取代了此前研究传统。D01

可以用“资源与数字版本—关联与计算分析—AI辅助理解与研究”观察方法扩展。这是本报告的归纳，不是严格分期。数据库、数字编辑、GIS、人工校勘仍有独立价值；2026年的AI研究也继续依赖这些基础。

例如，奥地利DHinfra在2026年10月开放相关研究教学项目申请，服务包括算力、数字化、存储及开源软件，显示一部分发展已进入共享基础设施运行。另一方面，牛津BodleianLLM在2026年9月启动，计划到2027年8月建设馆藏语料、评测和开放模型；截至本报告日期，它属于 进行中项目 ，不能把预期产出写成已经完成。DHinfra；BodleianLLM

3.3 中文语境的现实特点

中国国家图书馆的古籍资源、大学的数字人文中心、历史人物与地理数据库、古籍阅读与整理平台，已经提供了多种研究入口。2025年国图“中华古籍智慧化服务平台”上线试运行的官方说明，显示资源服务从影像阅读继续扩展到专题组织与知识服务；它并不等于全部古籍已有可直接研究的高质量文字。文化和旅游部转发国图说明，2025

中文研究的一个实际优势是材料问题明确：繁简与异体、竖排、双行小注、版本差异、人名地名歧义，都可以形成具体任务。但“有大量古籍”还不够，仍需核查版本、许可、标注质量与研究问题。2026年的古籍文档基准和历史OCR论文，为这些问题提供了新的技术与评测入口，见第5、8节及文献表。

3.4 研究团队常怎样分工

本报告建议用任务理解团队角色：材料与学科负责人判断版本和解释；数据负责人制定字段与标注规则；技术负责人实现清洗、模型或检索；质量负责人组织抽查、误差与复现；展示与维护负责人让成果可检查、可持续。小团队可以一人兼任，但关键判断应有第二人复核。

对初学者，材料整理、概念定义、标注规范、人工参照、误差分类与解释都是可以承担的研究工作。是否需要训练模型，取决于问题与验证结果；学习顺序可以从语料和评测起步。

4. 基础知识：先理解完整流程，再选择工具

4.1 一项文字型数字人文研究怎样走完

问题与材料范围 → 版本/来源/许可登记 → 获取影像或文本 → 转录与校对 → 结构化和标注 → 分析与对照 → 解释与细读 → 发布、引用和维护。

这是建议的工作流程，可以往返修改。例如，研究发现“某词少见”，要回查是语言现象，还是OCR漏识；发现关系网络有中心人物，要回查是否因为其传记较长。流程中的回查往往比再增加一个模型更有价值。

这些是本报告的教学释义。有关历史语料的元数据与标注，参见L15；关于AI辅助研究中概念与测量的关系，参见M04。不必先背熟所有英文，先能在自己的材料上指出对应环节。

4.3 数字文献最少要区分的几层

建议至少保留： 原件影像/原始文本；忠实转录；规范化文本；研究标注；推测或解释 。它们可以相互链接，不应互相覆盖。例如，异体字归一化便于检索，但原字形可能正是语言史研究对象；补出的缺字应明确是编辑者或模型的候选。

清洗、分类与编码包含研究判断。Rawson与Muñoz的《Against Cleaning》用数据整理案例讨论这一点；Drucker则提醒人文可视化需要表达选择、歧义和解释。它们支持记录处理决定，并不意味着识别错误应一律保留不改。D03；M01

5.2 古籍、档案为什么尤其难

困难来自多层组合：破损、透印、歪斜等图像问题；异体、俗字、生僻字和历史字形；竖排、双行夹注、眉批与印章；古汉语和无标点；同书异版以及现代点校改变。解决图像清晰度，只覆盖其中一层。O01；O06；O13

大规模数据也不等于全量专家金标准。HisDoc1B采用半自动构建，所查资源还存在非商业研究与机构申请审核条件；选数据集时应同时检查标注形成和实际获取门槛。O06

一条需要验证的误差链是： 罕见人名误识 → 纠错改成普通词 → 实体抽取漏人 → 网络关系改变 → 历史解释受到影响 。这是说明性假设，不是真实案例数据。已有研究证明OCR质量会影响不同下游任务，但影响程度随任务与材料而变化；不能为所有语种设一个通用可用阈值。O02

5.5 怎样评价“够不够用”

CER（字符错误率）的常见形式是： 替换数＋删除数＋插入数，再除以参考字符数 。插入很多时可能超过100%，所以不能一概写成“准确率＝1－CER”。中文使用词错误率WER时，还要说明怎样分词；标点、空格、繁简、异体字、Unicode规范化规则都会改变结果。O01

建议为实际研究增加四组检查，属于本报告的设计建议：

  1. 字与结构 ：漏字、错字、重复、漏行、正文/注释、阅读顺序分别报告。
  2. 证据敏感信息 ：单列人名、地名、年代、数值、罕见字；平均分可能掩盖重要错误。
  3. 工作成本 ：记录人工校对时间、疑字处理和返工，而不只记录模型推理时间。
  4. 下游结论 ：比较原始OCR、人工复核文本、自动纠错文本所得的检索、词频、实体或关系是否实质改变。

试点应先制定忠实转录规则，再组织独立复核。若要训练或调参，应按书、卷、作品或独立材料单元留出测试，检查近重复和跨版本重叠，避免同一本书相邻页面的相似性制造过于乐观的结果。

6.2 最先学的不是复杂模型，而是语料比较

检索行KWIC 把目标词放在中间，左右保留上下文，帮助逐条确认含义。 标准化频率 先约定按字、词等单位计数，再除以相应语料规模，减少仅由子库大小造成的差异；文类、作者、版本和识别质量仍需另外检查。 搭配 关注邻近词的反复共现。 关键词分析 比较目标语料与参照语料的突出差异，参照语料选什么会改变问题。

例如要研究某称谓的变化，应先固定或记录文类、年代、作者结构和版本。某时期出现次数增加，可能是语义/社会变化，也可能是该期收进了更多某类书。Pechenick等针对Google Books的研究，直接说明了语料构成对文化和语言趋势推断的限制；“被收录多”和“社会上更普遍”之间需要更多证据。L01

6.3 历时语义：一个重要的研究传统，也有清楚的反证

Hamilton等2016年用历时词向量研究语义变化，是经典入口。Dubossarsky等2017年通过控制条件说明，部分看似语言变化的规律也可能来自表示模型和频率偏差。两篇应对读：既理解技术能发现什么，也学习怎样检查算法是否自己制造了规律。L02；L03

2025年的方法进一步关注具体用例与可解释语义特征，例如研究法语“indigène(s)”的历史用法；同时，另一项研究发现，小规模预选词评测的好成绩不保证能从大词表可靠发现变化。对中文选题的启发是：比较简单搭配与模型方法，人工检查高分候选，并设置“本来不该变化”的控制条件；是否在中文同样有效仍需实测。L08；L09

6.4 古汉语研究已经有任务、资源和专门模型

WYWEB 把古文能力分成多类NLP任务； CHisIEC 提供古代史的实体与关系抽取语料； WenyanGPT/WenyanBENCH 将古文模型与任务评测结合。它们提供可起步的任务框架，但基准覆盖不等于各朝代、各文类和各群体都具代表性。L05；L06；L07

“古文理解”因此应继续细问：已转写文字的字义是否理解、断句是否合适、专名能否消歧、翻译是否保留含义、解释有没有原文证据、遇到多解能否说明不确定。识别原图字形属于前面的OCR环节，上述文本任务不自动检验看图能力。把这些合成一个笼统总分，会使研究问题不清楚。

6.5 历史文本修复：先产生候选，再接受学术检验

Ithaca面向希腊铭文的缺文、地域与年代判断；Aeneas进一步面向拉丁铭文的历史语境、平行材料检索及视觉信息。它们是AI与古代文献研究结合的代表案例。模型候选、研究者觉得有帮助、最终释读正确，是三种不同证据；不能把这些论文讲成通用古籍OCR已解决。L04；L12

6.6 语言学也可以研究模型本身

可研究模型怎样处理多义、指代、预设、讽刺、称谓、历史语境和文化概念。这时研究对象是模型行为；若用模型给真实文本贴标签，模型则是研究工具。两种研究需要不同的验证：前者测它怎样错，后者还须评估错误对材料判断和结论的影响，并说明适用范围与不确定性。M04

HistBench/HistAgent的正式版已发表于ICML 2026，提供涉及来源检索、多模态材料与多语历史问题的评测。它展示了工具协作的进展，也显示复杂任务依旧困难；不能把考试题、知识记忆和史料推理混为一谈。L14 2026年9月的Chronologic预印本进一步区分历史语境的识别与自由生成能力，但其英语出版材料和模型裁判有局限，仍待后续检验。L16

6.7 方言与少数民族语言需要更宽的成功标准

数字词典、音频例句、语法描述、社群参与和可持续保存，本身就可以是有价值的成果。Living Dictionaries相关研究与2026年语言记录计算方法综述，提供了这样的实践入口。评估应与使用者需求相连，不能只有模型分数。L11；L13

11.1 为你们当前准备阶段建议保留三条主线

主线A：可靠语料与OCR误差。 适合能接触古籍、档案、地方文献并能找到读懂材料的人。先研究错误和人文后果，再决定是否改模型。

主线B：语料与具体语言现象。 适合更喜欢中文语言、语用、文学和历史解释的人。先用真实例句、标注与简单统计形成证据，再加入复杂模型。

主线C：人文语言现象与模型评测。 适合既有人文兴趣，又想进入AI研究方法的人。把多义、指代、称谓、文化与历史语境定义成可检查任务，同时保留可多解和不确定情况。

这是准备阶段的比较判断，不是替你们决定最终方向。最强的共同底座是： 限定而清楚的材料＋可信人工参照＋一个具体问题＋能回到原件的证据链 。

11.2 用六项实际条件筛选，而不是只看题目新不新

  1. 能否拿到明确版本、用途许可合适的材料？
  2. 团队或导师中是否有人能判断关键字、史料与语言现象？
  3. 问题是否能用一批明确材料和可解释方法回答？
  4. 是否有第二人独立核查，能否保留分歧？
  5. 能否先做简单对照，再决定模型是否必要？
  6. 即使结果不如预期，是否仍能报告有价值的误差、边界或材料发现？

“覆盖全部古籍”“复原古人真实思想”“建一个能回答所有文史问题的大模型”都需要继续拆小，才能形成可验证计划。新颖性应针对具体材料、问题和方法组合检索，不能由“跨了两个领域”直接推出。

12.2 一次“不训练模型”的OCR入门试点

以下是操作方案， 尚未实际采集或运行 ：

  1. 选同一版本、有人能读懂、用途许可明确的一小组页图，写下一个词/人名/地名问题。
  2. 保存原图和页号对应；加工图另存，不覆盖原件。
  3. 保存原始OCR或人工初稿；约定异体、缺文、注释与标点怎样记录。
  4. 把文字对应到页、列/行和区域，正文与注释分开。
  5. 分类记录错字、漏字、多字、重复、读序错及编辑规范化。
  6. 第二人核关键内容和疑难，保留未决项与修改依据。
  7. 比较初稿和复核稿所得检索/实体结果，说明哪些改变影响了判断。

没有合适模型或整理账号时，可以先人工转录并建立参照。此时初稿与复核稿的比较属于转录审计；有实际OCR输出后，才在同材料上分析OCR误差。第一轮的成功标准是：另一位同学可以根据记录找到原图、理解修改、检查结果。工具路径见第9节。

12.3 一个语言学入门试点

限定一种称谓、句式或语用现象，选择来源清楚的同类材料；先共同读实例，拟定标签与反例；再由两人独立判断一小批，讨论定义问题，保留不一致。之后才扩大检索、比较频率和典型语境，必要时用模型辅助。

若比较时期，先看文类与作者结构是否可比；若比较模型，先固定测试材料和人工评价规则；若比较社会群体，说明材料记录的是谁的声音。不能由文本分布直接跨到没有材料支持的社会总体结论。
